# 品牌脱敏（小红书 / 抖音默认必做）

**默认执行，不用等用户开口。** 小红书已经明确：不能引导读者到站外，也不能在图上露出第三方平台、厂商品牌——一张卡里带"阿里云 / ECS / 域名 / 主机名"，整组都可能被判违规。所以出图前先脱敏，再渲染；渲染完再复核一遍，**0 命中才算过**。

## 0. 范围：这些要脱敏，这些不要

| 产物 | 脱敏 |
|---|---|
| 小红书卡片（`--platform 小红书`） | **默认做** |
| 抖音卡片（`--platform 抖音`） | **默认做**（与小红书共用一份内容时，脱敏一次，两边都用） |
| 站点文章 `article.md` / `rewrite.md` | **不脱敏**——那是给站内读者的，厂商名、域名、项目路径本来就是有效信息 |
| 公众号排版（站点原文） | **不脱敏**，跟站点文章一致 |
| 原文长图 / 原文卡片（`article.md` 输入） | 按目的地判断：发小红书、抖音才脱敏 |

判断只看**目的地**，不看来源：同一篇文，站点和公众号保留品牌，小红书和抖音的图卡脱敏。用户明确说"这篇不脱敏"时才例外。

**铁律：脱敏生成新文件，绝不覆盖已经发过的旧套。**
- 母稿新建 `content-合规.json`（或 `content-nodebrand.json`），原 `content.json` 一个字节都不动；
- 产物放新目录（如 `<渠道>/<slug>-合规版/<主题>-<平台>-<比例>/`），旧目录原样保留。


## 1. 字段级扫描清单

按字段扫，不要只搜正文。漏一个就白做：

| 位置 | 常见命中 |
|---|---|
| `source.title` / `wechat.title` | 厂商名、"在阿里云上…" |
| `source.url` | 站点域名、路径里的 slug（**直接置空**，页脚就只剩"原文｜作者·平台"） |
| `xhs.caption` | 厂商名、产品缩写（ECS）、平台名（GitHub Actions） |
| `xhs.tags` | 厂商名、平台名——标签比正文更容易被判定导流 |
| `pages[].intro`、`sections[].paragraphs` | 机型名、发行版名、路径、项目代号 |
| `sections[].card.text` / `bullets` / `claim.text` / `compare.*` / `timeline[].title` | 同上的缩写形式，正文改了大字常忘 |
| `sections[].figures[].src` / `note` | 图换没换、图注里有没有品牌 |
| `wechat.digest` | 摘要里的一句话版本 |

## 2. 替换对照（用在正文里，也用在图里）

原则：**换成品类词或技术等价描述，信息不失真；不写厂商、不写域名、不写项目代号。**

| 原来 | 换成 |
|---|---|
| 阿里云 / 腾讯云 / AWS | 云服务器 |
| ECS / CVM / EC2 | 服务器（"一台全新的 ECS" → "一台全新的服务器"） |
| Alibaba Cloud Linux 3 / Ubuntu 22.04（当它指向厂商生态时） | CentOS 系的 Linux 发行版 / Linux 发行版（保留"发行版"这一层，技术描述照样准确） |
| `/opt/XiaoBlog/dist` | `/opt/site/dist`（路径里的项目名一律中性化） |
| `https://<域名>/…` | 置空；正文别提"原文在 xx 站" |
| kicker / 页脚里的品牌口号 | 删掉，或换成中性的类目词 |

**默认保留**：`GitHub Actions`、`Nginx`、`Node.js`、`SSH` 这类开发者工具与协议名——它们是技术事实，不是导流通道。删了叙事就断（"提交代码就自动上线"讲不通）。
**只有用户明确要求更严时才替换**（如 `GitHub Actions` → `自动化部署`），并在交付时说明这是可选项。

## 3. 截图脱敏（最容易漏的一类）

终端截图、后台截图、体检表里常有三处品牌痕迹：

1. **命令行主机名**：`root@iZ2ze1lahuib1yxmq16k2Z`——`iZ…Z` 是阿里云实例命名法，等于写了厂商。整行裁掉。
2. **进程 / 组件详情**：`AliYunDun（安全组件）`。用背景色矩形盖住，再按原字号写中性描述（"安全防护组件，均属正常"）。
3. **客户端按钮 / 窗体外框**：底部"开启新会话"之类，属于工具品牌，一并裁掉。

**处理顺序**：先裁掉主机名行与底部按钮 → 再盖品牌词 → 再核对裁剪有没有切到正文（结论行常常只露半截，裁到正文结束 + 8px 才够）。

**踩坑**：
- 覆盖矩形起点要盖住左括号、终点要盖住右括号，否则留下 `）` 或 `（` 残骸；最稳的做法是**整段重写**而不是局部盖字。
- 字体用 `C:\Windows\Fonts\msyh.ttc`（size 与原文接近），颜色取原文字色，背景取行底色。
- **必须放大 4× 复核**，缩略图看不出括号残骸。

### 3.1 截图进不了卡片时，重排成同比例图（推荐）

卡片图框是固定比例：`.c-figcard .c-fig-box { aspect-ratio: 300 / 190 }`（≈1.579），图片按 cover 填充，**比例不符就左右裁切**——"维度"列、详情文字会被切掉，怎么调画布尺寸都没用（补上下边只是改变裁切量，比例仍是错的）。

两条路：
- **保留原截图**：把它做成 ≈1.579 的图（宽 900 → 高 570），内容留在中间，四周补同色背景；
- **重排一张**（更清晰，本案例采用）：用同一份数据重画深色表格（900×570，三列：维度 / 状态 / 详情，绿色对勾用线条画——微软雅黑没有 ✓ 字形，会显示成方块）。数据一字不改，只是排版，交付时说明"体检结果重新排版，数据未改"。

本仓库现成脚本：
```powershell
python "E:\works\New Journal\个人商业实战\scripts\health-check-card.py"   # 900×570 体检表（无主机名、无厂商组件）
```

## 4. 封面：品牌 ICON 必须换掉

封面是平台侧最显眼的一张，"封面露出了厂商 logo"等于直接违规。

- 阿里云橙色 ICON 这类素材**不能再用**；
- 但封面**仍然要有配图**（长期规矩：不做纯文字封面）；
- 解法：同一位置、同一尺寸换成中性图标（如"服务器机架"线稿，用主题强调色，不描任何 logo）。位置要与旧版一致，否则整组封面节奏会乱。

现成脚本（从**未叠过图标的原始渲染图**开始，重复叠会出现两个图标）：
```powershell
python "E:\works\New Journal\个人商业实战\scripts\cover-icon-neutral.py" card-01.png card-01-out.png
Move-Item card-01-out.png card-01.png -Force
```

叠完必须**重拼 `overview.jpg`**，否则总览里还是没图标的封面。

## 5. 复核（0 命中才交付）

1. **关键词扫描**：把 content 全字段（含数组、含 `pages`）过一遍，命中即修。
```powershell
$py = @'
import json, io
p = r"<目录>\content-合规.json"
d = json.load(io.open(p, encoding="utf-8"))
KEYS = ["阿里云","Alibaba","ECS","Aliyun","aliyun","xiaomaker","<项目名>","https://","http://"]
left = []
def scan(o, path=""):
    if isinstance(o, dict):
        for k, v in o.items(): scan(v, f"{path}.{k}")
    elif isinstance(o, list):
        for i, v in enumerate(o): scan(v, f"{path}[{i}]")
    elif isinstance(o, str):
        for k in KEYS:
            if k in o: left.append((path, k, o[:90]))
scan(d)
print("residual:", left if left else "none")
'@; $py | Out-File -LiteralPath "$env:TEMP\scrub.py" -Encoding utf8; python "$env:TEMP\scrub.py"
```
2. **页脚 / 来源行**：打开卡 14 和任意一张卡，确认页脚只有"原文｜作者·平台"，没有域名；`source.url` 置空后卡 14 的来源段会缩短，需要目视一遍不要出现"，，"这类残句。
3. **逐张看图**：`overview.jpg` 看整体，`card-01`（封面图标）、图卡（截图边缘）、`card-14`（来源段）必看。
4. **文案**：`caption.md` 全文过一遍，标题、正文、标签都不能有厂商名和域名。

- 截图是"重排"还是"遮盖"，数据有没有改；
