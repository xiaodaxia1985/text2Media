更直接的一条：EP02 的 `cover-vertical.png` 是 `ffmpeg -ss 0` 从成片抽的第 0 帧——**抽帧就是截图**，平台说的就是这件事。

### 第 2 轮（2026-11-22 EP04）：去掉零件还不够，**类目**错了

零件全清干净之后，横版仍然连续被判，五版对照如下：

| 版 | 长相 | 结果 |
|---|---|---|
| v3 | 浅底 + 人像卡带 1.5px 赤陶边线 | 判「截屏」 |
| v4 | 浅底 + 无框人像卡 + 柔和投影（去掉了边线） | 判「截屏」 |
| v5 | 深墨底 `#1A1F26` + 无框人像卡 | **竖版通过；4:3 与 16:9 判「截屏」** |
| **v6** | **满幅剧照铺满 + 压暗渐变 + 反白大字** | **9:16、4:3、16:9 三张全部通过** |

**结论（以后直接按这条走）：平台横竖封面位要的是「视频帧」，不是「海报」。**

- 纯色底 + 一张小卡 + 小字 = 海报 / 网页截图 → 判「截屏」
- 人像铺满整幅 + 大字压暗区 = 视频帧 → 通过
- 平台自己在提示里给的参考封面，全是满幅人像压大字——照它做，不要自己发明版式。

**别再拿比例、清晰度、裁剪框、文件大小去找原因。** 这些都不是变量：v5 的 4:3 和 16:9 尺寸与格式完全正确，同一套图的竖版还通过了，差别只在「像不像一帧视频」。

## 二、铁律（违一条就返工）

1. **三张封面各有一个独立 Composition，一律 Render 出图**：`EPnnFV9`（9:16）/ `EPnnF16`（16:9）/ `EPnnF43`（4:3）。
2. **禁止从 mp4 抽帧当封面**。
3. **9:16 / 4:3 / 16:9 一律走「满幅照片」类目**：人物照片铺满画幅 + 压暗渐变 + 反白大字。**不许**纯色满底、不许卡片边框、不许把人像缩成一小块嵌在色底里。
4. **3:4（小红书首图）暂时保留 `QCover` 人像卡片式**：小红书没判过截屏，先不动；要统一时按本文档同一思路新建 `QFull`，不许直接把 3:4 裁成 9:16。
5. 封面只许**四件**：角标（`13 集 · 第 N 集`）、两行标题（稿内「封面标题」原字样，一字不改）、一句副标（开篇句）、人物照片。
6. 页眉页码 / 刻度条 / 页脚线 / 竖条 / 外框 / 网址域名二维码 **一律不许进封面**。
7. **照片必须离线裁好再铺**：现场只允许 `<Img>` 铺满，**不许让 CSS 从 1280×720 原帧直拉到 1920 宽**（糊、且会出现素材里没裁干净的角标/字幕）。
8. **素材必须裁掉平台烧录的角标与字幕**（口径见第三节）。裁完核验**顶 24px 无亮块**。
9. **标题与副标必须带双重 `textShadow`**，否则字压在人脸亮部读不出。
10. **封面组件全系列共用一份**（`engine/src/pieces/cover/CLEAN.tsx`），各集只写文字常量（`SPEC`），不许为单集手写坐标。
11. 文字块不许顶在上半屏、下半空一片；竖版底部 **264px** 留给平台 UI，不放任何结论或署名。

## 三、素材准备（一次做对，后面每集复制）

源帧口径（EP04 起）：**1280×720 剧照，干净区 `y 100–596`**。

- 上界 100：避开左上角标的白底（实测白底像素下沿 y≈97）
- 下界 596：避开烧录字幕（约 y 600–700）
- 净高 496，人脸水平中心 `x ≈ 668`

三张底图（`engine/public/assets/<slug>/`，落盘后不许再改名）：

| 输出 | 尺寸 | 裁窗 | 放大 | 落盘名 |
|---|---|---|---|---|
| 9:16 | 1080×**1360**（下半接黑） | 394×496 @ x471 | **2.74×** | `portrait-full-9x16.png`（成品 1080×1920） |
| 16:9 | 1920×1080 | 882×496 @ x227 | **2.14×** | `portrait-full-16x9.png` |
| 4:3 | 1440×1080 | 661×496 @ x337 | **2.14×** | `portrait-full-4x3.png` |

生成口径（PIL）：

```python
im.crop((x0, 100, x0 + cw, 596)).resize((W, H), Image.LANCZOS)
   .filter(ImageFilter.UnsharpMask(radius=1.6, percent=60, threshold=3))   # 竖版 percent 55
```

**竖版底图的两个必做动作**（缺一条就出废图）：

1. 照片区只铺 **0–1360**，下面接深色 `#0B0E12`；
2. 渐变必须**在照片底边之前收满**：`F0=1080 → F1=1355`，曲线 `alpha = (y-F0)/(F1-F0)` 开 **1.35 次方**，`F1` 以下全黑。
   → 不做这条，照片在 1360 处会留一条**横向硬边**（EP04 第一版就栽在这里）。

## 四、实现入口

`engine/src/pieces/cover/CLEAN.tsx` 导出三件：

| 组件 | 画幅 | 说明 |
|---|---|---|
| `VFull` | 9:16 | 照片满幅 + 顶部 340px 压暗 + 字压暗区 |
| `HFull` | 16:9 / 4:3 | 照片满幅 + **左侧**三段压暗 + 字在左栏 |
| `QCover` | 3:4 | 人像卡片式（小红书，暂用） |

各集 `pieces/epNN/COVER.tsx` 只留一个 `SPEC` 常量 + 三行导出：

```ts
const SPEC: CoverSpec = {
  kick: '13 集 · 第 4 集',
  title: ['一条视频100万播放', '然后呢？'],  // 稿内封面标题原字样
  sub: ['其余每条只有一千，', '这个号算做成了吗？'],  // 开篇句
};

export const COVERV_FULL = () => <VFull spec={SPEC} src="assets/ep01/portrait-full-9x16.png" />;
export const COVER16_FULL = () => <HFull spec={SPEC} cfg={H16} src="assets/ep01/portrait-full-16x9.png" />;
export const COVER43_FULL = () => <HFull spec={SPEC} cfg={H43} src="assets/ep01/portrait-full-4x3.png" />;
```

三条 Composition 统一 **80 帧、取第 79 帧**（`COVERH_FRAMES`），保证 `appear` 走完再出图。

| 元素 | 值 |
|---|---|
| 底图 | `portrait-full-4x3.png`，`Img` 铺满 |
| 左侧压暗 | 同 16:9 |
| 角标 | left 80 / top **313** |
| 标题 | left 80 / top **383** / `fit(title, 140, 706)` / 行高 1.15× |
| 副标 | left 80 / top **683** / 32px / 行高 50 |

**字号不手调**，按最长行反推：

```
em   = Σ(汉字 1 / 数字与字母 0.55)
raw  = min(cap, 可用宽 / em)
size = floor(raw / 4) * 4        # 吸 4px 档，且 ≤ cap
可用宽：9:16 = 888（1080-96×2）｜16:9 = 1000（1120-96-24）｜4:3 = 706（810-80-24）
cap：9:16 = 120｜16:9 与 4:3 = 140
```

各集实出（满幅类目口径）：

| 集 | 最长行 | 9:16 | 16:9 | 4:3 |
|---|---|---|---|---|
| EP04 | 一条视频100万播放（8.65 em） | **100** | **116** | **80** |

## 七、与成片首帧的关系

`opening.md` 的 SC01 三态开场里，第 1 帧是「封面态」。**2026-11-20 起封面与成片首帧解耦**：封面是独立 Composition，成片首帧服务于视频内开场，不必充当平台封面。

但两者**数值要同值**（铁律 16 要求同构）：同一集里，封面标题字号 / 人像位置 / 角标字号必须与 SC01 首帧对齐，2–4px 的差也要对上，否则平台首帧预览和封面图会错位。

2026-11-22 晚起封面改满幅照片类目，**SC01 首帧暂按旧口径（人像卡片式）**：EP04 因发布在即不追溯重渲；**EP06 起 SC01 首帧要直接按 `VFull` 出**（照片铺到 1360、字压 1204），不再回头改。
