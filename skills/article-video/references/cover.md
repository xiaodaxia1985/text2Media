# 封面口径（跨系列通用，2026-11-20 定，改就返工）

## 起因

2026-11-20 EP02 上传抖音，横版封面被平台拒，原文提示：

> 封面优化建议 · 请勿使用截屏当封面

查出来不是画质问题，是**封面把视频内页的零件整套搬了过来**。旧封面上有七件东西：

| 零件 | 平台读成什么 |
|---|---|
| 13 格刻度条 | **进度条** |
| `NO. 02 / 13` | 播放器页码 |
| 页眉 `DAN KOE` + 顶部细线 | 播放器标题栏 |
| 页脚线 + 「个人商业创造者」 | 播放器底栏 |
| 左侧赤陶竖条 | 播放器装饰 |
| 人像左缘纸色渐变 | 截图抠图痕迹 |
| 画面四周留白外框 | 截图边框 |

更要命的一条：**EP02 没有竖版封面 Composition**，`cover-vertical.png` 是从成片 mp4 抽的第 0 帧。抽帧＝截图，平台说的就是这件事。

## 铁律

1. **三张封面各有一个独立 Composition**（`EPNN C` / `EPNN C16` / `EPNN C43`），一律 Render 出图。
2. **禁止从 mp4 抽帧当封面**（`ffmpeg -ss 0` 出的东西平台会判截图，且与版式无关）。
3. 封面只许**四件**：角标（`13 集 · 第 N 集`）、两行标题（稿内「封面标题」原字样，一字不改）、一句副标（开篇句）、人像。
4. 人像**必须出血**：竖版铺满 1080 宽、下缘到底；横版铺满画幅高、右侧与上下出血。不许留外框、不许左右留白、不许硬边（接纸色处加 160px 渐变）。
5. 页眉页码 / 刻度条 / 页脚线 / 竖条 / 外框 **一律不许进封面**。
6. 文字块垂直居中：上留白 ≈ 下留白，不许顶在上半屏、下半空一片。
7. **封面组件全系列共用一份**（`engine/src/pieces/cover/CLEAN.tsx`），各集只写文字常量，不许再为单集手写一套坐标。写完一集才发现字号越界、开始手调，就是没走这一条。

## 实现（2026-11-20 起唯一入口）

`engine/src/pieces/cover/CLEAN.tsx` 导出 `VCover`（竖版）/ `HCover`（横版，配 `H16` / `H43` 两套尺规）。各集 `pieces/epNN/COVER*.tsx` 只剩一个 `CoverSpec` 常量 + 三行导出：

```ts
const SPEC: CoverSpec = {
  kick: '13 集 · 第 N 集',
  title: ['第一行', '第二行'],   // 稿内封面标题原字样
  sub: ['副标第一行', '副标第二行'], // 开篇句
  vCap: 100,                     // 可选：竖版字号上限，默认 116
};
export const COVERV = () => <VCover spec={SPEC} />;   // → EPnnC  1080×1920
export const COVER16 = () => <HCover spec={SPEC} cfg={H16} />; // → EPnnC16 1920×1080
export const COVER43 = () => <HCover spec={SPEC} cfg={H43} />; // → EPnnC43 1440×1080
```

**字号不手调，按最长行反推**：

```
em = Σ(汉字 1 / 其余 0.55)            最长行字数换算
raw = min(cap, 可用宽 / em)
size = floor(raw / 4) * 4             吸到 4px 档，且 ≤ cap
可用宽：竖版 888（=1080-96×2）、16:9 1000（=1120-96-24）、4:3 706（=810-80-24）
```

各集实出（2026-11-20 八集通用后实测）：

| 集 | 最长行 | 竖 | 16:9 | 4:3 | 备注 |
|---|---|---|---|---|---|
| EP01 | 最值钱的技能， | 108 | 124 | 88 | 8 em，116 会撑破 888 |
| EP02 | 三条路怎么选 | 116 | 140 | 100 | 7 em，走到 cap |
| EP03 | 这门生意有多大？ | 108 | 124 | 88 | 8 em，`vCap 108` |
| EP04 | 一条视频100万播放 | 100 | 116 | 80 | 8.65 em（数字 0.55），`vCap 100` |
| EP05 | 能值多少钱？ | 100 | 116 | 80 | 6 em，用户定稿 100，`vCap 100` |

三条 Composition 统一 **80 帧、取第 79 帧**（`COVERV_FRAMES = 80`）；早期 EP03/EP04/EP05 的竖版是 24 帧纯静态，已随本次改造一并统一，避免 `appear` 动画没走完就出图。

## 验收清单（出一张核一张）

- [ ] 图里没有任何刻度条 / 页码 / 页脚线 / 竖条 / 外框
- [ ] 人像出血到画幅边缘，接纸色处无硬边
- [ ] 标题是稿内「封面标题」原字样，标题两行都在画面内不切断
- [ ] 文字块上下留白大致相等
- [ ] 尺寸：1080×1920 / 1920×1080 / 1440×1080，PNG
- [ ] **不是**从 mp4 抽的帧（`Get-Item cover-vertical.png` 时间应晚于该集 mp4 的渲染时间，属于独立 Render）

## 与成片首帧的关系

`opening.md` 的三态开场里，SC01 第 1 帧曾是「封面态」（带页眉与刻度）。2026-11-20 起**封面与成片首帧解耦**：
封面是独立 Composition，成片首帧仍是 SC01 的画面（它服务于视频内的开场，不必充当平台封面）。

EP01–EP05 已发布，封面按本口径重出即可，**不追溯重渲成片**；EP06 起新集直接按本文件建三个 Composition。
