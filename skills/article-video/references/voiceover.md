# 从文章到口播稿（voiceover）

**口播稿是这条线的主角。** 画面、版面、运镜、大字全部是为它服务的；稿子不成立，后面每一步都是给一段不成立的话配图。
所以这一层单独成工序，**换任何一篇文章都按同一套走**，不靠某一篇的手感。

## 一、先回答三个问题，再动笔

| 问题 | 答案要写成什么 | 答不出来会怎样 |
|---|---|---|
| 这篇在回答**一个**什么问题？ | 一句话。如"他辞了，为什么钱还在他手上" | 答不出＝文章只是并列段落，写出来必然跳跃 |
| **谁**是主角？他的身份怎么一句说清？ | 人名＋身份＋事件＋时间，至少给三项 | 第一句写"他"，观众不知道"他"是谁（v1 就是这么废的） |
| 观众**看完该带走**什么？ | 1–3 句结论，口径照原文结尾 | 没有落点＝听完记不住，评论区会说"讲了个啥" |

## 二、选一条骨架，不许混

| 骨架 | 适用 | 顺序 |
|---|---|---|
| **事件—疑点—解答** | 新闻、人物动态（本篇） | 发生了什么 → 大家为什么慌/看不懂 → 钱/能力的答案 → 结论 |
| **时间线—转折** | 人物传记、创业史 | 起点 → 第一次生死 → 关键下注 → 今天 → 结论 |
| **问题—三层原因—结论** | 观点文、方法论 | 现象 → 原因一/二/三 → 所以怎么办 |
| **误区—真相** | 科普、辟谣 | 大家以为 X → 其实是 Y → 证据 → 边界 |

**混骨架是"跳跃"的第一大来源**：一会儿讲钱、一会儿讲 1993、一会儿讲飞机，各段都对，但观众找不到自己在链条的哪一格。

## 二·补、开篇三镜：主题和结论必须先出来（2026-11-16 定）

口播不是推理番。观众不会等你铺垫到第 10 秒，**第一句就要同时交代「这篇讲什么」和「结论是什么」**。只给半句、把答案压到第 3 镜，前 10 秒全是悬念，人已经滑走了。

| 镜 | 干的事 | 写法 | 反例（都被否过） |
|---|---|---|---|
| 01 | 主题＋结论合成一句 | 把原文标题里的判断直接读出来：对象＋最稀缺/最关键的是什么＋结果 | 「AI 的下一个十年，最缺的不再是把东西做出来」——只否定不给答案，观众还得往下等 |
| 02 | 交代为什么不是别的答案 | 先用一个 6–12 字的短句立起对照（「做东西已经便宜了」），再给证据 | 直接甩数字，观众不知道为什么此刻要听这个数字 |
| 03 | 自己的判断／转折 | 一句立场句，把讨论往前推一格 | 再复述一遍 01 的结论，等于空转 5 秒 |

四条硬规矩：

1. **结论落在开场 15 秒内**（片头 + 01 + 02），不晚于第 3 镜。
2. **01 不许只否定不给答案**：「不再是把东西做出来」「不是技术问题」这类留白式开场一律改。
3. **03 不许复述 01**，只能往前推一格（01 说「最稀缺的是验证和负责」，03 说「卡住的地方已经挪到生成之后」——同一件事的下一步，不是同一句的重播）。
4. **结论句优先逐字取原文标题**。标题是作者已经压过一遍的判断，拿它开场比自造一句稳；改写只做口语化，不换判断强度。

整片骨架（含片头片尾）：**片头（账号介绍，≤5 秒）→ 01 主题＋结论 → 02 为什么 → 03 判断 → 正文取证 → 片尾（关注/点赞/收藏，2 秒）**。

片头为什么不放在结论前面：5 秒账号介绍会把刚抛出的钩子打断，抖音的黄金三秒就白扔了。结论紧跟片头，观众在第 5–10 秒拿到这件事，仍在安全区内。

**片头、片尾这类新增段落，先把文字稿交人确认，确认前不写组件、不配音、不渲染。** 文字没定就开做，做多轮都是白做——这条比排版重要。

## 二·补二、正文通则十条（2026-11-17 定，跨体裁通用）

**这一组管「怎么推进」，不管「讲什么」。** 三篇不同体裁跑下来（观点文《验证与担责》、个人实验《90 天做第一个产品》、产业文《农业产业链金融》），十条都成立；而《验证与担责》的「验证／担责」「做出来→不稀缺」一次也没被带进另外两篇——**那些是那篇文章的结论，是实例，不是规则**。写新稿时如果冒出来的还是上一篇的结论，说明规则没落地，只是在套模板。

动笔前先读原文全文。只读标题、导语或摘要就动笔，必然砍掉一半意思（v8 只讲「可信」丢掉「担责」就是这么来的）。

| # | 规则 | 层 | 实例（只作示例，不许当规则复用） |
|---|---|---|---|
| 1 | 开篇先抛核心判断（反常识、大判断），不先抛数据 | 结构 | 「过去十年最难的是把东西做出来，可从今年起它不稀缺了」 |
| 2 | 判断之后立刻给一层粗证，不展开 | 结构 | 「报告、代码、客服，成本一路往下」 |
| 3 | 用「接下来稀缺的是 N 件事」把主题收窄 | 语言 | 「就两件事：证明它对、有人担责」 |
| 4 | 三个论点用「先说／再看／最后」给路线图 | 结构 | 正文三段各报一次到 |
| 5 | 每个论点＝论点句＋1–2 个硬数据或案例＋一句把它翻译成人话 | 结构 | 「84% 在用，46% 不信」→「用得越多，越不信它准」 |
| 6 | 一个论点至少 2 个案例，每个 1–2 句 | 结构 | 加航 812 加元／德勤 237 页里 14 处编造 |
| 7 | 案例之后必须给「代价归谁」的归因 | 语言 | 「掏钱的是加航，不是模型」 |
| 8 | 多条论据要「合起来」收成一个判断，用原文的瓶颈句 | 结构 | 「卡住的地方是：这个结果可不可信」 |
| 9 | 结尾＝身份转变＋三个可执行动作；个人叙事／实验体裁换成「承诺或悬念」 | 结构 | 观点文：「从把东西做出来的人，变成让结果可信的人」；90 天篇：「过程真实，判断可追溯」 |
| 10 | 虚词不砍，一句一口气（≤38 字） | 语言 | 「信它准的只有三成三」，不是「只三成三」 |

几条补充，落笔时按这几条判：

1. **1／2／4／5／6／8／9 是结构规则，3／7／10 是语言规则。** 结构规则换任何体裁都要用；语言规则管的是「说人话」的最低线。
2. **规则 5 的「翻译句」不是起手式。** 直接把结论说成人话，别用「说白了／说穿了／先说结论」开头——那是 `lieflat-less-ai-tone` 规则 3 明确要删的。它的 X 级清单里「这意味着」永不改，需要显式点出因果时可以用。
3. **规则 9 两个变体按体裁选，不许混。** 观点／产业类走「身份转变＋三个动作」；个人叙事、实验记录类走「承诺或悬念」（承诺过程真实、判断可追溯，或留一个下一步的悬念）。硬把「三个动作」套进个人叙事，会变成给自己派任务。
4. **规则 1–3 就是「二·补」那三镜。** 镜次排法以「二·补」为准，这条只保证正文第一句不是数据、不是铺垫。
5. **十条只管推进，不给字数。** 字数由原文信息量决定：讲得完就短，讲不完就长——**不许为压时长砍承接句和虚词**（这条已被批过三次）。

## 三、立主语（硬规矩）

1. 第一句必须出现**主体名**，且不得以"他 / 她 / 它 / 其 / 该 / 这位"开头。
2. 主体名第二次出现之后，才允许用"他"。
3. 一篇文章里主体只有一个人时，不要在中间换成"英伟达""该公司"来指人——人与公司必须分清（本篇"他"是黄仁勋，"它"是英伟达，不许混）。

## 四、写句：一镜一句，一句一个信息点

- 长度：**6–38 字**，一律 26–36 字会把节奏写"齐"（实测：句长 CV 0.314，人类中位 0.54；两句同构 400/百段，人类 5.52）。**长句旁边放一个 6–12 字的短句**，短的是落点。
  ——这条是 2026-11-16 用 `lieflat-less-ai-tone` 检测后补的：原规则"12–38 字"把 13 句全压成 26–36 字，检测直接报"节奏均匀 + 相邻句同款"。
- 一句只放**一个信息点**＋**一个承接词**；两个信息点就拆两句。
- 动词往前放，别套三层定语：「他为什么把股权锁这么死？」优于「关于其股权锁定安排背后的深层原因」。
- 数字用原文口径（"三十多块""上亿美元""八元"），不要换算成"约 30 元人民币"这种二手说法。
- **动词必须带对象**（2026-11-16 被指出"一看就是 AI"）。「裁掉七成」——七成什么？口播没有画面可看，省掉的宾语就是观众断掉的那一秒。AI 爱省，因为它默认读者知道上下文；观众没有上下文。
  - ❌ 那年路线走错，钱见了底，**裁掉七成**，账上只够三十天。
  - ✅ 那年路线走错，钱见了底，**裁掉七成员工**，账上只够三十天。
  - 同类：营收翻了三倍（翻三倍的是什么，得说"营收"）／利润涨了两成／省下四成成本。
  - `vo_check.py` 的 R7 管这条：动词＋数量词，后面直接是逗号或句号就算"缺对象"。
- **虚词不许为压字数砍掉。**「信它准的只有三成三」不是「信它准的只三成三」——口播靠虚词撑语气，砍掉就成电报腔，这是 AI 最爱犯的减字病（用户原话：「AI 最喜欢减字」）。字数是结果，不是目标。
- 不写"值得注意的是""不得不说""在某种意义上"——这些是口播里的刹车片，删掉不影响信息。

## 五、承接测试（这条决定"连不连贯"）

两个机械可查的动作：

1. **首词回指**：第 2 句起，每句开头必须咬住上一句里的词或被上一句逼出来的问题。
   本篇实际用到的：`接棒的是 / 市场慌的是 / 而且这上千亿 / 他为什么把股权锁这么死 / 活下来之后 / 他的生活在另一头 / 他也 / 所以 / 说到底`。
2. **删句测试**：把任意一句删掉，读下一句——**悬空就必留，不悬空就是冗余**。
   例：删掉"他为什么把股权锁这么死？要回到 1993 年…"，下一句"活下来之后，他才敢…"立刻悬空；删掉"豪车若干"，下一句照样通——那句就是可以砍的。

## 六、去 AI 味：调 `lieflat-less-ai-tone`，不自建词表

**这一层不归本 skill。** 去 AI 味要用仓库里已有的 `skills/lieflat-less-ai-tone`（三层：detect.py 分级报告 → 语义层判读 → 人审），它有 629 篇对照 + 270 对配对的实测结论，本 skill 只负责把稿子交过去，不另写词表。

```powershell
python skills/lieflat-less-ai-tone/scripts/detect.py <稿子.txt> --min-chars 0 [--json > before.json]
```

**`--min-chars 0` 是 2026-11-16 为本条线加的**：那支 skill 原本写死"汉字 <500 不检测"，而 60–90 秒的口播稿通常只有 300–400 汉字。加了这个参数之后短稿也能跑，脚本会在 stderr 提醒"密度类指标只作参照、显著性不成立"，命中仍逐条复核。

它的工作流是「先出改前报告、等人回复、再改写、再复测」。**到了这条产线上，"等人回复"这一环取消**：规则说得清的项目按白名单直接改，只有规则判不了的（比喻贴切度、暗喻、三个案例是否凑数）留人审。

| 项目 | 处置 |
|---|---|
| F 级 分号密度超标 | 直接拆句（拆完不丢层级就拆），不征询 |
| 规则 1 翻案腔、规则 2 提示语冒号、规则 3 起手式、规则 4 翻译腔 | 直接改成正面判断/删除提示语 |
| 规则 6 相邻句同款、规则 13 三连同构 | 拆掉其中一句的骨架；刻意的结论排比保留 |
| 规则 10 同义重命名 | 统一回原名词，零信息损失 |
| 比喻贴切度、暗喻、拟人、案例凑数 | **不判、不改**，报告里列人审区 |

**两条边界要知道：**

1. **短稿能跑了，但密度指标只作参照。** `--min-chars 0` 让 300–400 字的口播稿也能出报告，只是每千字密度在这么短的样本上算出来是噪声，看命中项别看倍数。真正的判读仍按它 SKILL.md 的 13 条规则来。
2. **别自己发明词表。** 那个 skill 的 X 级清单明确写着"漂亮词黑名单（赋能/闭环/抓手）δ+0.10 不显著，永不改"、"名词化/明喻/设问/模糊量词全部 |δ|<0.2 永不改"。我先前在 `vo_check.py` 里塞的"空话词表"跟它的实测结论直接打架，已经删掉了——`vo_check.py` 现在只管结构（谁开口、一句多长、接没接上、数字有没有出处），不管文风。

| 谁管什么 | 归属 |
|---|---|
| 第一句有没有主角名、单句长度、首词回指、数字出处、时长 | `article-video/vo_check.py` |
| 翻案腔、冒号提示语、翻译腔、同款句、同义重命名、密度指标 | `lieflat-less-ai-tone/detect.py` + 语义层 |
| 比喻贴切度、暗喻、拟人、三个案例是否凑数 | 人审（那个 skill 明确不碰） |

## 七、交付形态

口播稿落成 `talk.json`（每镜：`id / headline / line`），因为后面三步都吃它：
`headline` 是屏幕大字（必须是 `line` 的逐字前缀，`talk.py` 会断言）；`line` 是台词，也是 `build_script.py --lines` 与配音的唯一文本来源。

**一篇文章的口播稿 typically 8–12 镜、250–350 字、60–80 秒**；这只是本篇的落点，不是规范：讲得完就长，讲不完就砍镜，不许为了时长把承接句砍掉。

## 八、本篇的落点（样例，供下次对照）

- 骨架：事件—疑点—解答
- 主语：第 1 句"黄仁勋，英伟达的创始人"
- 10 镜 / 330 字 / 约 72 秒
- 承接词链：接棒的是 → 市场慌的是 → 而且这上千亿 → 为什么锁这么死 → 活下来之后 → 另一头 → 也 → 所以 → 说到底
