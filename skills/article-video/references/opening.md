# 开场定式（一镜兼封面，三态不切屏）

> 2026-11-20 EP04 定版。**这一条已经被否过两版才定下来，别再重新发明。**
> 适用：Dan Koe 13 集系列，以及今后所有同底座（`engine` + `vbase/tokens` + `epbase/ed`）的竖版篇目。

---

## 一、要解决的问题

1. **点开第一秒没声音**（用户原话「用户点开这个视频前一秒是没有声音的？这样不合适」）。
2. **封面与正文之间「太跳跃」**（第一版做法：0.8 秒满版封面 → 硬切正片，用户否：「这种方式不得行，太跳跃了」）。
3. **封面信息没有去处**——封面讲的问题，正片第一镜换了另一套版式重讲一遍，观众要重新认一次页面。

三条其实是同一个病：**把封面当成一段独立的前置片，而不是第一镜的开场画面。**

---

## 二、定式（照做，不许改结构）

**一镜三态，全程不切屏、不加时长。** 第一镜（`SC01.tsx`）同时是平台封面和三段式开场的载体。

| 相 | 镜内帧（30fps） | 画面 | 声音 |
|---|---|---|---|
| ① 封面 | **仅第 1 帧**（2026-11-22 起；EP01–EP03、EP05 是旧的 1–24 帧 0.8s） | 人物照片铺满 + 两行大字（= 稿内「封面标题」原字样）+ 副标 + 集数标签。**无刻度尺、无页眉、无页脚线**（2026-11-21 用户定：首帧的 13 格刻度＝进度条，抖音直接判截屏）。**封面只停 1 帧**——停满 1 秒＝前 3 秒没人动，抖音 2 秒跳出 47.53% | 旁白第 1 句已在念（`narration.wav` 从第 0 帧起） |
| ② 总纲 | N2 退封面层 → **N10 总纲立起**（N26 前必须立起） | 封面层 N2 起退净（角标 12 帧、副标 16 帧、**人像最后 N6→26**）；标题原位不动，`A ≠ B` 在 462 一带浮出 | 同 |
| ③ 证据 | 双柱 **N28 起**（基线 N24）/ 三格 **N40 起** | 两种形态：**双柱**（量级差 → 柱从基线升起 + 两个数字 + 「柱高已压缩」注 + 判词）/ **三格**（同一件事的三种看法 → 三张卡逐格亮 + 判定格 118 帧起长赤陶底线 + 注 + 判词）。坐标见第三节两张表 | 同 |

四条硬约束：

1. **成片第 1 帧必须与 `cover-vertical.png` 同构**：标题逐字、字号、行距、位置全部照抄封面组件（`pieces/epNN/COVER.tsx` 里的常量），不许在这一镜另起一套坐标。平台取首帧当预览，差一行字就是两张封面。**照抄的具体清单**：标题**硬写与封面组件同值的字号 + `nowrap`（不许用 `Huge`，它会 fitLines 缩字）**；照片用该集离线裁好的 `portrait-full-9x16.png` **铺满**；**刻度尺 / 页眉 / 页脚线 / 基线都不能在第 1 帧出现**。验收办法：`still.ps1 -Frames '0'` 出一帧，与 `cover-vertical.png` 并排肉眼比对，元素逐一对齐即过。
   > **封面类目 2026-11-22 晚变更**：9:16 / 4:3 / 16:9 一律改为「满幅剧照铺满 + 压暗渐变 + 反白大字」（口径见 `cover.md`）。EP04 因发布在即**不追溯重渲**，首帧仍是旧卡片式；**EP06 起首帧按 `VFull` 出**——但封面态标题在 1204、总纲在 462，两处位置不同，**必须先出一版过渡方案报批**，不许把标题从下部直接跳到中部。
2. **不拼独立封面段**。旧的 `EPxxC`（24 帧纯封面）**不再进成片**，只在出发布物料（竖版 / 4:3 / 16:9 三张图）时渲末帧用。成片 = `正片 → 落款段 SIGN12`，两段。
3. **不许加 sonic / 音效**。声音只有旁白 + −13dB 垫乐（淡入 0.2s）。2026-11-20 先做过一版两拍钢琴 sonic（A4→E5，0.55s），用户否：「开头的哪一个钢琴音符去掉」。
4. **总纲绝不占柱区**。总纲行在标题正下方（462），柱区 690–1250 留给柱子。总纲放中央再退、柱子同期升起 → 半透明白字叠在赤陶柱上，渲出来是一团糊（实测 2.9s 帧）。

## 三、竖版 1080×1920 参数表（以 EP04 2026-11-22 第四轮为准）

> 规矩只有一条：**本表数值必须与该集封面组件同值**。EP03 / EP05 的标题 top、副标 top、人像尺寸各不相同，各自照自己的 `COVER.tsx`，不许混用。

| 件 | 值 |
|---|---|
| 页眉 | `Head N no="04"`，top 116 / 线 166；**N12 起 14 帧淡入**（等集数标签退净，否则两行叠在左上角） |
| 集数标签 | left 96 / top 150 / **22px mono** / 字距 3 / 灰；**N2 起 12 帧退**，只在封面相存在 |
| 标题 | **手写两行，不用 `Huge`**：left 96 / top **236 与 344** / `FONT_HEAVY` 250 / **与封面组件同值（EP04 = 100px）** / `lineHeight:'108px'` / `nowrap`。`Huge` 会按 888 宽跑 `fitLines` 反推字号，与封面硬写的字号必然差一档 |
| 副标 | left 96 / top **492** / **36px / 行高 56 / 字重 250 / `#55554F`** / 两行；**N2 起 16 帧退**（30px 在抖音单格里只剩 9px 字高，和 400 一样糊） |
| 刻度 | **不设**（2026-11-21 用户定：第 1 帧的 13 格刻度条＝进度条，抖音直接判截屏；成片与封面图一律没有这一件） |
| 总纲 | `A` left 96 top 462 64px；`≠` left 302 top 448 76px 赤陶；`B` left 400 top 462 64px；`10 / 14 / 18` 帧逐个进，**全程不撤** |
| 基线 | `BaseLine x=96 y=1250 w=888`，**包一层 `opacity: clamp01((N-24)/8)`**——封面态（1–24 帧）不能有这根线，否则第 1 帧多一条横线，≠ 封面图 |
| 双柱 | 左 `x=120 w=380 h=560` 淡陶 `accentPale`（N28 起 / dur 42）；右 `x=580 w=380 h=30` 赤陶 `accent`（N30 起 / dur 42） |
| 数字 | 左 left 150 / 64px（N64）；右 left 610 / 64px 赤陶（N70） |
| 注 | left 96 / top 1272 / 24px mono「柱高已压缩 · 实际差 1000 倍」（N82） |
| 判词 | `Rule at=94 top=1330`；字 left 96 / top 1356 / **40px**（N102）→ **N140 原地升 56px 赤陶**（两个元素叠着换显隐，别直接改字号，闸门 B 硬要求 1356 位存在 `fontSize:40`）；赤陶「？」left 830 / top 1362 / 120px（N112） |
| 人像 | EP04 现值：`PortraitCard` 674×990 @ (203,700) 卡片式（旧口径，见下方变更说明）；EP03 是 `dankoe-portrait-3x-s45.png` 1080×1220 满宽铺到 y1920 + 顶部 190px 纸色渐变。**N6→26 退净**（+`scale 1→0.985` 退后感） |
| 页脚 | `Foot N at={50}`（等人像退净才淡入，提前出会压在人像上），线 1698 / 品牌 1726 |

**退场节奏（2026-11-22 第四轮定，取代旧的 1.27s 版）**：**封面只停 1 帧**，N2 起退、**0.9s 内退净** —— 集数标签最先（N2 起 12 帧）、副标（N2 起 16 帧）、**人像最后（N6→26）**；柱子在 N28 起，等人像退净才起，否则半透明的脸压在柱子上。

**为什么改成停 1 帧**：抖音后台 2 秒跳出 47.53%、平均播放 8.31s、完播低于 88% 同类。停满 24 帧（0.8s）等于前 3 秒画面不动。

**三格变体（EP01 / EP02 / EP03，证据不是「双柱量级差」而是「同一件事的三种看法」时用这一套）**

| 件 | 值 |
|---|---|
| 总纲 | 只有一对短词时：`A` left 96 top 500 72px；`≠` left 184 top 484 84px 赤陶；`B` left 286 top 500 72px；**34 / 40 / 46 帧**逐个进（`appear(N-34,14)` 之类），**与三格重叠、全程不撤** |
| 三格 | `left = 96 + i*300` / `top 800` / **276×300** / 1px `C.line` 边 + `C.card` 底；起帧 **40 / 46 / 52**（`appear(N-40-i*6,12)`） |
| 格内 | 序号 22px mono（26,20）；主语 32px 重字；副标 24px 灰（48 / 54 / 60 帧起，`appear(N-48-i*6,10)`）；✕/✓ 标记同步 |
| 二段变化 | 判定格（通常是第三格）**118 帧起**从左长一条 6px 赤陶底线（`width 276*appear(N-118,16)`），把「答案是这一个」坐实 |
| 注 / 判词 | 注 76 帧（`left 96 / top 848` 一带）；`Rule 84`；判词 92 帧 |
| 人像 / 页脚 / 退场 | 与双柱版完全一致（人像 10→48 退，`Foot` 页脚） |

**为什么三格必须从 40 帧起**：第一版照 EP04 的「柱子 48 帧起」推到 78 帧（2.6s），结果 1.6–2.6s 只有总纲一行、下半屏整片空白，读成空镜。三格是「并排卡片」，起点可以更早、与总纲叠着长，不需要等人像退净。

## 四、怎么生成（新一集的落地步骤）

1. **取字**：稿内「封面标题」行 = 标题两行，逐字不改。开篇句拆成副标两行（如「其余每条只有一千，／这个号算做成了吗？」）。
2. **定总纲**：本集只讲一件事的两面对立 → 取稿内注视两个原词，中间一个赤陶 `≠`（如「注意力 ≠ 品牌」）。**不许自造句子**，也不许用一整句长句（长句只能一头一尾两行，中间全空，实测难看）。
3. **定证据**：先判这一集的开篇是「一对量级差」还是「同一件事的三种看法」——前者用**双柱**（柱顶数字承担量级；真实比例画不出，1000:1 时右柱只有 0.47px，所以柱高只表达"有量级差"，基线下注明「柱高已压缩」）；后者用**三格**（每格一句最短的主语 + 一行副标，判定格最后点亮）。两种都可以，但一集只用一种。
4. **写组件**：新建 `engine/src/pieces/epNN/SC01.tsx`，坐标照第三节抄，`CoverLayer` 的元素直接复写 `COVER.tsx` 的坐标常量 —— **不要 import 复用一个"封面层"组件**（封面还要出三张不同画幅，两边混在一起会互相牵制）。
5. **封面三图**：`COVER.tsx` 导出的 `COVERV_FULL / COVER16_FULL / COVER43_FULL`（满幅照片类目，2026-11-22 晚定），渲末帧取图（`still.ps1 -Frames '79'`）。口径见 `cover.md`。
6. **渲与拼**：`render.ps1 -Comp EPxx` → ffmpeg concat 拼 `SIGN12` → `mix_bgm.ps1 -BgmDb -13`。**两段，不是三段。**

## 五、反面教材（都试过，别再走）

| 做法 | 结果 |
|---|---|
| 封面 24 帧纯静图 + 正片硬切 | 「太跳跃了」——0.33s 内整页版式换一套 |
| 封面层用透明度淡出、柱子同期升起 | 半透明的脸叠在赤陶柱上，成一团糊（2.9s 帧） |
| 封面人像用纸色块从下往上擦掉 | 人像被"截断"在中段，像裁切错误 |
| 总纲放中央大字、退场后柱子再起 | 中央空 1 秒（结论没了、柱还没长），面板上读成空镜 |
| 两拍钢琴 sonic 放开头 | 「开头的哪一个钢琴音符去掉」——只好旁白 + 垫乐 |
| 总纲写成一句 88px 长句 | 只有首行出得来，第二行 drip 延迟，中间全空 |

## 六、验收（出片前逐条量）

- [ ] 成片第 1 帧与 `cover-vertical.png` 同构、肉眼一致（同字、同位置、同字号、照片同尺寸）
- [ ] **第 1 帧没有刻度尺、页眉、页脚线**（2026-11-21 用户定：首帧刻度＝进度条，抖音判截屏）；页脚 `at={50}` 人像退净后才出
- [ ] **封面只停 1 帧**（EP04 起），N2 起退、0.9s 内退净；总纲 N10 前必须立起
- [ ] **任意连续 45 帧（1.5s）内至少一处可见变化**：`ffmpeg -vf "scale=108:192,format=gray" -f framemd5` 抓逐帧 hash，相邻同 hash 即静止，全片不许有 ≥45 帧静止段
- [ ] 第 1 帧无基线横线（基线随柱 44→52 帧才淡入）
- [ ] **页脚右侧账号名 = 「个人商业创造者」**（不是「个人商业实战」——那是项目文件夹名，2026-11-20 用户纠偏）；唯一来源是 `epbase/ed.tsx` 的 `Foot` 默认 `right`，COVER 组件里写死的也要改
- [ ] 第 1 帧就有旁白声（`ffprobe` 音频起点 = 视频起点）
- [ ] 全程无切点：抽 0.0 / 0.6 / 1.0 / 1.5 / 2.6 / 4.9 帧，版式是同一页在变，不是换页
- [ ] 0.6–1.5 秒之间没有"人像没了、证据没起"的空窗；三格版在 1.4 秒（42 帧）时必须已见第一格
- [ ] 总纲行与柱区不重叠（总纲底 ≤512，柱顶 690）
- [ ] 成片 = 正片 + `SIGN12` 两段，帧数 = 正片 + 180
- [ ] 无 sonic；垫乐 −13dB，混后 LUFS 与无乐版一致
