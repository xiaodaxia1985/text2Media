# 长片布局节奏（36 镜以上不许长得像同一张表）

**适用**：一镜一族、族数 ≥ 6、总镜数 ≥ 20 的元素动画长片（本文按 36 镜 / 6′44″ 定标）。
**不适用**：≤12 镜的短片——短片的敌人是「单镜不够狠」，长片的敌人是「镜与镜同构」。两套判据别混用。

出处全部是官方文档原文与开源仓库规范，不是自创审美：官方 `remotion-create/video-layout.md`、`remotion-markup/multi-scene-video.md`；社区 Remocn、snapcn、anything2explainer、sessionmovie（链接见文末）。

---

## 一、先分清：官方只管什么，社区管什么

| 层 | 谁定 | 原文 / 判据 |
|---|---|---|
| 编排结构 | 官方 `multi-scene-video.md`（全 258 字） | 每个实景一个组件；父结构二选一：独立起点用命名 `Track`（items 不可重叠），随时长变化仍相邻用 `TransitionSeries`（overlap 计入总时长）。**它只管结构，不管画面轮换。** |
| 单帧构图 | 官方 `video-layout.md`（全 125 字） | "Decide what the viewer should notice first in each scene. Build the frame around that one thing." 1080p 下主标题 **84px**、重要辅文 **44px**、关键文字距边 ≥80px / 上下 ≥100px、"Do not add redundant elements." |
| 镜与镜的差异 | 社区 | Remocn："Every beat the same length → kills rhythm; the video drones""every panel pops in on the same frame"；snapcn：一个 beat 一种镜头类型，帧数 47–240 不等；anything2explainer：主图 <110px 撑 >45 帧＝缺陷、set-piece 每章 ≤1 |
| 一致性的位置 | sessionmovie | 一套 panel chrome + 一套动效语法（200/400/800ms），**一致性放外框，内部布局才敢放开** |

**结论一句话**：在官方文档里找「长片布局怎么轮换」是找不到的，官方只给「每镜一个第一眼主体 + 字号下限」。**轮换的方法必须来自社区规范，且必须收敛成可执行的配额与约束**，否则就是猜。

---

## 二、四条根因（诊断顺序，不许跳）

1. **族 = 版式**。族一复用就撞脸。族应该 = **骨架类型**（横轴/竖轴/网格/环/单点/满版），版式由「骨架 + 方向 + 体量 + 内容」现场生成。
2. **没有第一眼主体**。一根线 + 几枚 34px 胶囊撑 100 帧，是 anything2explainer 明文点名的缺陷；官方 84px 下限就是这条的另一种说法。
3. **没有级差**。全是中景，观众看不出哪一镜更重。长短片都怕这个，长片尤其。
4. **连续性同构**。连续三镜是「线长出来 → 标签亮」时，第三镜观众已经知道你下一招。

---

## 三、骨架只有六种，差异靠三个维度做乘法

| 骨架 | 一句话 | 适合的句子关系 |
|---|---|---|
| 横轴 | 一条轴从左贯到右，节点沿轴排 | 顺序、时间线、多步（**全片 ≤2 处**，最易滥用） |
| 竖轴 | 自上而下分层，层与层有承接 | 层级、递进、一轮接一轮 |
| 网格 | N×M 并列块，可推近/可点亮 | 枚举、分布、组队、清单 |
| 环 | 闭合回路，有跑动的小球或游标 | 循环、返工、闭环 |
| 单点 | 画面只有一个巨物（一个字/一个数/一个口） | 判断、停顿、验收、留白 |
| 满版 | 全幅底色块 + 巨字，无其他结构 | 开场、鸿沟、回扣、收尾 |

**乘法**：6 骨架 × 3 体量 × 2 方向（左起/右起、上起/下起）× 4 纹理（官方 `@remotion/effects`：`paper / halftone / dotGrid / scanlines / lines / vignette`）= 144 种形态。36 镜只用 36 种，永远够。

**反直觉的一条**：种类越多越像。真正结构不同的只有这 6 种，第 7 种以后都是同一种「细线+小字」的变体，加进去只会稀释。

---

## 四、三个体量档 + 配额（长片节奏的全部秘密在这里）

| 档 | 定义 | 占比 | 作用 |
|---|---|---|---|
| **S** 满版重击 | ≥90 帧独立编排，主体占画面 ≥55% 面积，通常换底色 | **每章 1 个**（36 镜=4 章=4 个） | 换气 |
| **M** 中景主图 | 有一个 ≥170px 的图形主体或 ≥96px 大字 | 主力（≈75%） | 讲事 |
| **D** 细节快切 | 只放一个巨物 + 一行短标，≤60 帧的轻拍 | 每章 1–2 个 | 打点 |

**配额（FAIL，不是建议）**

- S 档全片 = `ceil(镜数/9)`，且不相邻；每章 ≤1。
- D 档每章 1–2 个，与 S 档间隔 ≥4 镜。
- 每 **5–6 镜**必须出现一次「全幅变化」（S 或 D 或换底色/换纹理的满幅动作）；36 镜→至少 6 次。
- 运镜（推近/横移/升降）每章 ≥3 次，每镜 ≤1 次。
- 单镜 ≥120 帧；一镜 ≤1 个焦点动作。

---

## 五、方向配额（用户原话「水平时间轴出现很多次」的正面解）

| 方向 | 全片上限 | 理由 |
|---|---|---|
压横轴 ≤2（必须带主角） | 横轴是最容易被当成"默认版式"的一种 |
| 环 ≤2 | 环重复会读成"又绕了一圈" |
| 左右分栏 ≤2 | 并列栏读成 PPT，并列栏类族（C）全片 ≤1 |
| 竖轴 ≤N/6 | 竖轴可复用，但要换内容层级 |
| 网格/单点/满版 | 不设上限，靠体量与纹理区分 |

**连续性约束（生成时用，不靠眼看）**
1. 连续 3 镜方向不得相同；连续 2 镜族不得相同。
2. 同族再次出现，必须换体量或换方向（只换文案不算换）。
3. 每章镜数 ≥6 时，章内至少出现 4 种不同方向。
4. 章界必须有承接：上一章末镜的最后一个动作，是下一章首镜的第一个动作（同族可跨章复用一次，作为"回扣"）。

## 六、选骨架：句子关系 → 骨架（查表，不许即兴）

| 句子在说什么 | 骨架 | 第一眼主体 |
|---|---|---|
| 顺序 / 步骤 / 时间 | 横轴或竖轴（≥4 步用横轴，≤3 层用竖轴） | 当前那一步（放大 1.15） |
| 层级 / 底座 / 一套东西撑住上层 | 竖轴 | 最宽的那一层 |
| 并列 / 枚举 / 分布 | 网格 | 被点亮的格 / 最大的那个数 |
| 循环 / 返工 / 闭环 | 环 | 环 + 卡住的那个点 |
| 落差 / 两笔账 / 多与少 | 双柱或天平（竖轴变体） | 差额数字 |
| 一个判断 / 一次停顿 / 一个签字 | 单点 | 那个字或那个数（≥96px） |
| 鸿沟 / 全场一句判词 / 收尾 | 满版 | 巨字（≥120px） |
| 类比具象物（天平、插头、闸门） | 自绘一组具象元素，**每片 ≤2 处** | 具象物的动作终点 |

## 七、长片才有的两个手段（短片用不上，长片必须有）

1. **母题回扣**：第 1 章建立的形态（三行大字 / 疤 / 章），在末章以同一形态、不同内容回扣。作用是把「重复」从缺陷变成结构。36 镜片里至少 1 次。
2. **换视觉体系 2–3 次**：整片只用一套纸色撑 6 分钟会平。允许在章界切换底色（纸→墨→纸），每次切换配一次 S 档。

## 八、机器校验（把"好看"变成可测，别靠眼睛）

1. `frame_max_object.py`：成片缩到 480×270，逐帧算最大连通亮块的高度，剔底部字幕带。输出每镜主体高度中位数；**<110px 且持续 >45 帧 → 缺陷**，**<80px → 严重**。
2. `rhythm_check.py`：读 spec 表，输出 36 行 × （镜号/族/骨架/体量/方向/主体尺寸），标红违反第三～六节任一条的行。
3. 分章渲染、分章验收：一章一渲一校，不和整片一起赌。

**改法优先级**：先补第一眼主体（第二节第 2 条）→ 再调配额（第四节）→ 最后换骨架（第六节）。顺序反了会白改。

## 八·补、每族的「主体补法」清单（2026-11-17 逐镜改出来，全部 props 驱动）

按优先级第一步（补主体）动手时，**不要重新设计一族，只在这族里把某一样东西放大到能当第一眼**。逐族落法：

| 族 / 骨架 | 第一眼主体 | 具体尺度（1080p、BOX=1640） | 被降级的配角 |
|---|---|---|---|
| 比例条（O） | **百分比数字**，不是条 | 数字 96px，固定在轴右端外侧同一列（`left+轴长+46`，宽 340），形成"数字墙"；条高降到 22px | 条、刻度、行标签 30px |
| 落差（G） | **柱顶数值** | 84px 标在柱顶上方（`base - h - 100`）；柱宽 360 | 柱身、行标签 34px；**note 大字数删**（数值已承担同一信息，官方 `Do not add redundant elements`） |
| 双栏（C，2 列） | **末列大块** | 末列 `colW*0.78 × 240` 橙描边；首列 `150×150` 小局部块（局部/整体的对比） | 列标签 52px、序号 20px |
| 分栏（C，≥3 列） | 全部等大 | `colW*0.70 × 170`，只用描边色区分 | **不许把末列做大**——并列项被做大，观众读成"最后一项才是重点" |
| 路径链（I） | **末节点** | 节点 76px、末节点 120px 强调色；回环虚线 `strokeWidth 9`、`18 14` 断线 | 序号 20px、标签 44px |
| 断口（L） | **断口符号** | ✕ 半宽 50、描边 11px；框 600×260；右框内再套 1.5px 虚线空框表示"没接上" | 框内标签 52px |
| 四格回扣（T） | 末格 | 2×2 卡 780×220，末格强调色；短标签 ≤4 字用 76px、中 56px、长 44px | 序号 24px |
| 满版（B） | **三行巨字** | 150px / 末行 168px（原来 70/86 根本不算满版），行距 208，宽度给到 1560 | 橙线、tag、24px 脚注 |

再补一条**去冗余**：镜内已经有 `note` 大字时，`foot` 不再渲（`foot && !note`）。L 族实测两处都是「脚注与底部字幕同一句」，一屏两套字。

两条从这一轮抽帧里得出的硬判据：

1. **只有一个数，不要用比例条。** 单条比例条在 1080p 上占不到 1/3 画面，剩下全是空——这一镜交给巨数字族（D）。比例条至少两根才成立。
2. **回收章不要再用第 5 根横轴。** 四个案例/四件事的回扣用 2×2 四格（T），横轴全片仍守 ≤2。

**验收方法**（改完先抽单帧，别直接渲整段）：`still --frame=N`（N < 该镜 frames），逐条对照上表；同时看三处最容易压字的位置——序号与大字的间距（序号上移到 `y+62`、大字 `y+96`）、大字与块顶（块顶 `y+190`）、note 与块底（note `y+h+70`）。

## 九、不要做的事

- 不要自造新族来「制造差异」——新族就是新一种版式，加进去还是同一张脸（本项目已否过一次：「新增竖向导轨族」被用户当场否掉）。
- 不要给每镜加 glow / 渐变字 / ALL-CAPS / 宽字距来「显高级」——这是 Remocn 的 generic 清单，越加越像 AI 片。
- 不要用 crossfade 掩盖撞脸：转场不是节奏，级差才是。
- 不要用同一时长摊平所有镜：帧数由配音定，但**镜内拍子必须按内容重量分**（重镜 2–3 拍，轻镜 1 拍）。
- 不要把「一致性」理解成「布局一致」。一致性 = 外框 + 字幕 + 一套动效语法 + 一套色彩；布局必须变。
