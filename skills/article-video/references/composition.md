# 构图几何（1080p 横版定版）

出处：video-talkcraft `references/layout.md` 的九项校验 + Remotion 官方 `video-layout.md` 的字号下限。
本文件把它改成我们的纸色体系与 1640 内容区，作用只有一个：**出图之前把几何定死，出图之后用闸门量**。

## 0 为什么要有这份

我们的图反复出同一批毛病：卡片贴边、字压邻列、框没套住字、独句缩在角落、间距内大外小、字幕带被占。
这些不是审美分歧，是**没有几何数值**——每次靠"看着还行"就必然复发。

## 1 画布与三条线

- 画布 1920×1080；内容区 `BOX = 1640`、`PAD = 140`（比通用安全边 96 更严，沿用 `theme.ts`，不改）
- 中线 `y = 540`；三分线 `y = 360 / 720`
- **字幕带 `y ≥ 940` 只放字幕**（`CAPTION_STYLE` 从底 62 起）；主体下沿 ≤ 900 更安全
- 元素离画布边 ≥ 140；**< 96 即判贴边**（P1）

## 2 12 栏栅格

内容宽 1640，gutter 32 → **栏宽 107.33**；栏线 `x_i = 140 + i × 139.33`（i = 0…12）。
元素左右边缘**吸附栏线**，容差 ±4px。常用跨度：

| 用法 | 跨度 |
|---|---|
| 全宽 | 12 |
| 主列 / 侧列 | 8 / 4 |
| 双列 | 6 + 6 |
| 三列 | 4 + 4 + 4 |
| 一主两辅 | 7 + 5 |

## 3 间距令牌

只用 **8 / 16 / 24 / 32 / 48 / 64 / 96 / 160**，不许随手数。

**层级铁律：外边距 ≥ 组间距 ≥ 组内间距**（96 ≥ 48~64 ≥ 16~32）。
间距倒挂（中间空 400、外侧挤 40）读作"两坨东西各自贴边"。修法是**整组收进栏格再居中**，不许拿 margin 硬救。

组内相邻元素等距 ≥ 24；标题与其下内容 ≥ 32；章节级标题与内容 ≥ 96。

## 4 六档字阶

| 档 | 字号 | 用途 |
|---|---|---|
| hero | 96–120 | 单句独占一镜、金句 |
| title | 64–72 | 镜内标题 |
| well | 44 | 副标 / 跟读字幕 |
| body | 40–44 | 列表条目、chip、卡内正文 |
| caption | 28–32 | 图注、辅助说明 |
| micro | 22–24 | 来源行、序号 |

- 最小可读 **28**；**列表条目 / chip ≥ 40**（低于 40 等于没有，这条在 390px 缩图上验）
- 标题字数 → 字号：≤6 字 120 / 7–10 字 96 / 两行各 ≤8 字 84 / 两行 9–12 字 72 / 三行 64。**超了拆行，不缩字**
- 同屏 hero : body **≥ 2:1**；字重两档（hero 600、title 700），不加到 800+

## 5 对齐与居中

- 同组元素左边缘对齐同一栏线（或整组右对齐），不许各自为政
- **以字形边缘为准，不以容器盒为准**：色块 / 胶囊 / 图标与文字同组时，色块左边 = 标题首字左边；有 padding 的元素反向补偿
- 无人物在场时，主体**包围盒**水平居中（不是第一个元素居中），偏差 **> 48px 判 P1**
- 双元素组：宽度比 1:1 或 2:1，间距 32–64，顶边对齐，整组居中
- 数字用 `tabular-nums`，同一行的图标 / 数字 / 文字对齐基线

## 6 标注（框、圈、下划线、箭头、取景框）

- 几何由目标**实测反推**（`measureText` / `getBoundingClientRect`），四边留白 16–24 等距，**不目测**
- 抽定妆帧核对，偏差 **> 8px 返工**
- 我们踩过的：对角 L 框一边离字 80px、一边压到末字下方——框没套住字

## 7 碰撞与溢出

- 任意两个元素包围盒**不得相交**。例外只有三类：标注压素材、字幕带、chip 压 B-roll
- 文字块列宽 ≥ 最长行实测宽 + 2×padding；文字不越出自己的列
- 放不下时的顺序：**先删字 → 再拆行 → 最后才缩字号**
- 溢出分档：1–40 微调 / 40–90 局部收紧 / 90–160 压标题或正文 / **> 160 换版式或删内容**

## 8 定妆帧九项（每镜出图后逐项打勾）

① 贴边（离画布边 < 96）
② 间距倒挂（组内 > 外边）
③ 左边缘未吸附栏线 / 未按字形对齐
④ 包围盒未居中（偏差 > 48）
⑤ 标注未套住目标（偏差 > 8）
⑥ 字号低于档（条目 28 / 列表 40 / 独句 hero 96）
⑦ 包围盒相交
⑧ 同组底板同色 / 章节卡同色
⑨ 缩到 390 宽不可读

任一项失败 = **P1**，改完再渲这一段。

机器可测的 ①④⑥⑦ 交给 `scripts/frame_max_object.py`（主体高度、贴边、字幕带占用、最大块居中偏差），其余靠人眼，且必须看**成片缩到 390 宽**那一版。

## 9 色板从哪来（先找，不许新起）

一支片子的色板**不是每次重新选**，是**继承**：

1. **项目里已有主题就继承**：先找 `theme.ts` / `tokens.ts` / `design-tokens.json` 一类文件（本项目在 `video/step4-motion/src/theme.ts`）。有就整套照搬：纸色、墨色、accent、muted 一个都不改，只为深底派生一档 accent 提亮色。
2. **没有主题才定档**：按 `tools/video-talkcraft/references/design-language.md` §0 的领域 → 风格档选一套，定完写进项目 `theme.ts` 存档，后面所有片子继承。
3. **accent 全片只有一个**：深底上的提亮色是它的同色派生，不构成第二个 accent。
4. **pastel 只给并列项**，且必须与 accent 同温（冷 accent 配冷 pastel，暖 accent 配暖 pastel）。混温 = 彩虹色。
5. **深底必须与 accent 同温，暖纸系主题一律不许满版**：暖灰纸 + 赤陶这套里，冷调的墨蓝灰铺满版就是两套体系（47 镜已否掉）。暖纸主题全片零满版深底，重量交给巨字、赤陶块、accent 顶线；冷色系主题才允许深底，且直接取 ink 本身，不另起纯黑。

> 反例（2026-11-18）：47 镜骨架先套了 talkcraft 的纯白 + 苹果蓝，与本项目既有 `theme.ts`（暖灰纸 `#F5F5F5` + 墨蓝灰 `#2D3142` + 赤陶 `#BF4520`）完全是两套，用户当场否掉。**骨架可以借，色板必须继承。**

## 10 一句话记住

**栅格定位置，令牌定间距，字阶定大小，实测定标注，九项定合格，色板先继承再定。**
