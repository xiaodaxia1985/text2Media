# 画面关系 → 画法（一镜一设计）

出处：anything2explainer `reference/narration-storyboard.md` §4 模式表 + `reference/composition-and-light.md` 三档尺寸；
video-talkcraft "纯文字镜必配线稿陪衬""并列项逐个出现""一致性放外框、内部放开"。

本文件解决的是**"为什么一支 76 镜的片看起来像同一张表"**：因为我们把「族」当成了版式，
20 个族撑 76 镜，平均每 4 镜重复一次——观众第三镜就认出模板。

## 0 三条硬原则

1. **一镜一设计**：版式从"这一镜要说的话"长出来，**不从族库里挑**。族只提供画法语法（线、块、字、环、轴），
   位置 / 尺寸 / 叙事角色由这一镜的关系决定。
   （anything2explainer 的做法就是 one component per shot：44 镜 44 个组件，重复率 0。）
2. **一致性来自 token，不来自版式重复**：色板、字阶、栅格、字幕带、动效曲线固定；**布局必须变**。
   一致性放外框，内部才敢放开。
3. **唯一的开关是底色**：换幕换底色是允许的一致性手段（浅 → 深 → 浅），版式不进这个开关。
   （原文：one visual style, on purpose, with a single switch — the backdrop。）
4. **满版深底看主题温：暖纸系零次，冷色系 ≤3 次**。暖纸（`#F5F5F5` 一类）+ 暖 accent（赤陶 / 赭石）的片子里，冷调深底铺满版会立刻分裂成两套视觉体系（47 镜否掉过墨蓝灰 `#2D3142`）。暖纸系的重量靠巨字 + 赤陶实心块 + accent 顶线；冷色系才允许深底，且 ≤3 次（开篇 1 + 收尾 1 + 中间最多 1）。中间章界一律不靠亮度反转换气。

## 1 每镜三步，不许跳

1. **这一句的关系是什么** → 查 §2 表
2. **第一眼主体是哪一个** → 只许一个，且可量化：图形 ≥ 170px / 字 ≥ 96px（1080p）
3. **配角降到哪一档** → ≤ body 40，辅助说明 ≤ caption 28

三步都写下之后才允许画；写不出第一眼主体，说明这一镜还没想清楚讲什么。

## 2 二十二条关系 → 画法

| # | 画面关系 | 画法 | 第一眼主体 | 常见错 |
|---|---|---|---|---|
| 1 | 一个主体 + 几个组成部分 | 主体居左或居中，组件沿边逐个长出 | 主体轮廓 ≥170px | 组件比主体还大 |
| 2 | 类比具象物（天平/闸门/插头） | 自绘具象物 + 动作终点 | 具象物的动作终点 | 全片 > 2 处 |
| 3 | 主角登场 | 单主体 + 一行短标，深底 | 主体 ≥55% 面积 | 一堆字围着一个小图标 |
| 4 | 有序过程 / 步骤 | 轴 + 游标；≥4 步用横轴，≤3 层用竖轴 | **当前那一步**（放大 1.15） | 各步平均用力，看不出走到哪 |
| 5 | 点集 / 分布 / 邻近 | 网格，只点亮当前格 | 被点亮的格 | 九格三等分、没有重点 |
| 6 | 层级 / 地基 / 塔 | 自下而上堆叠，逐层加宽 | 最宽那层 或 当前层 | 层高小于字高，压成一条线 |
| 7 | 容器 / 准入（门 → 名单） | 门框 + 穿过的小块 | 门口那块 | 画成流程图 |
| 8 | 两路汇合 | 两条线向右汇到一点 | 汇合点 | 两条线粗细一样 |
| 9 | 漏斗 / 筛选 | 上宽下窄三段，数字标在收口 | 收口数字 | 用宽度暗示没有的比例 |
| 10 | 曲线 / 趋势 | 坐标轴 + 一条线 + 拐点标注 | 拐点 | 无刻度的装饰线 |
| 11 | 请求 → 回应 | 左发问框、右回答框，中间箭头 | 回答框 | 两框一样重 |
| 12 | 并列清单 | 列表条，**逐条出现**（0.6s 一条） | 第一条 | 三条一起淡入 |
| 13 | 取舍 / 天平 | 左右两框，一实一虚 | 被选中那框 | 两边一样实 |
| 14 | 网络 / 生态 | 中心点 + 环绕节点 | 中心点 | 节点等大 |
| 15 | 循环 / 返工 | 环 + 跑动小球，或断口 | 卡住的那一点 | 环太大占满画面 |
| 16 | 大数字 / 量级 | 巨数字 + 单位后置 | 数字 ≥120px | 数字与单位同字号 |
| 17 | 收尾 / 回扣 | 满版，首章形态换内容再来一次 | 三行巨字 | 又起一个新结构 |
| 18 | 时间轴 | 横轴 + 时段分段 | 当前时段 | 全片 > 2 次 |
| 19 | 公式 / 换算 | A = B × C，三块等宽 | 等号右边结果 | 用文字叙述代替算式 |
| 20 | 对照表 | 2×2 或 2×3，一格亮 | 亮的那格 | 四格全亮 |
| 21 | 很多 / 世界很大 | 密集小点 + 一句判词 | 判词（hero） | 点数太少看不出"多" |
| 22 | 两种做法像、其实不同 | 左右同形，差异处画圈 | 差异处 | 靠文字解释差异 |

## 3 尺寸与光（1080p）

- 图形主体 **≥170px**，字主体 hero **≥96**（金句 120）；单镜 **≤1 个焦点动作**
- 光跟主角：亮底 → 主角压暗或加描边；深底 → 主角提亮；反差色只给主角**一处**
- 主角落中线或上三分线，底边 ≤ 900（让开字幕带）

## 4 纯文字镜的两条保命规则

1. **文字不裸放**：纯文字镜必配线稿示意图（ink 3px 描边 + accent 只强调一处 + 白板托底）。这是我们最早的病——一屏只有几行字，观众读完了还不知道在看什么。
2. **独句独占一镜 = hero 96–120 + 居中 + 底板保可读**，**不许缩成 44px 胶囊贴角**（那是"有字但没讲"）。

## 5 什么时候允许"套卡"

只有一种：这一镜的关系在 §2 表里查不到，且已有一张卡的形状与它**同构**。
套卡也必须改三样——字阶、衬底、强调位置。三样都不改 = 换皮不换画法，观众仍然认出模板。

## 6 两道闸门，缺一不可

| 闸门 | 管什么 | 判据 |
|---|---|---|
| `scripts/rhythm_check.py` | 整片节奏（方向 / 体量 / 连续性 / 配额） | 0 违规 |
| `scripts/frame_max_object.py` | 这一镜立不立得住（主体高度 / 贴边 / 字幕带） | 主体 ≥110px（<80 FAIL）、不贴边、字幕带不被占 |

版式配额过、但单帧主体立不住，观众看到的仍然是"一张表"；单帧漂亮、但整片方向重复，观众看到的是"同一个模板放六分钟"。

## 7 骨架级定妆：一镜一原语，三处结构性易错

长片定妆帧不必一镜写一个组件。可以先用一组**原语**（hero / pair / triad / list / grid / tower / axis / curve / quote / schematic / crowd / gaps / stack / loop / f）铺满，**每镜一行数据、版式由数据决定**——但仍是一镜一种画法，不是一族撑到底。

三条结构性错误必须写死在数据里，不能靠事后看图发现：

1. **塔的层级方向**：地基在最底、越往上越窄。`texts` 一律按"从顶到底"给，点亮索引跟着改。反了会把"地基"读到顶上（24 / 36 / 37 / 38 四镜都踩过）。
2. **时间轴默认正序**：早 → 晚 从左到右。只有台词明确"倒着数"时才传 `rev`，且必须写进该镜数据（16 号"上午/中午/下午"曾整条反）。
3. **细笔画大字不等于细笔画**：96–190 号细体字，笔画只有 6–10px，闸门若只按连通块量会被拆成几十个碎块、误判"没有主体"。定妆帧闸门**必须**有行投影兜底（见 §8）。

并列块（triad / list / stack）另有一条下限：**块内文字 ≥ 40，块高 ≥ 240**。低于这个，1200px 宽的条里字只剩五六十号，画面读作"空"。

## 8 闸门口径（frame_max_object.py 的实际判据）

| 参数 | 值 | 为什么 |
|---|---|---|
| `TOL` | 18 | 要认出 ALT 底卡（与纸底差 28）和 pastel（差 30–42），同时滤掉抗锯齿 |
| 膨胀 | 3×3 三遍 | 把笔画聚成字、字聚成行；细体大字不做这步永远测不到 |
| `bh` | `max(连通块高, 行投影最长连续内容带)` | 两种度量互补：连通块抓图形，行投影抓细笔画大字 |
| 主体高 | ≥110 通过 / <80 FAIL | 纯文字镜按字高判，108–124 号字刚过线 |

背景色取**四角采样**，底板必须纯色。contact sheet（多格总览）会被 `check_shape` 按非 16:9 拒收——别拿总览图喂闸门。
