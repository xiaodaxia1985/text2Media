# 图表画法（a2e 原样搬 · 竖版 9:16）

> 2026-11-19 定。**全套走 a2e，不引入别的库、不自己造图元。**
> EP03 第一轮静帧坏 7 镜，根因是「从零手画 div 图表」：坐标目测、箭头用 `rotate` 拼、拿 64px 小 Glyph 当主体。
> 解决办法不是再画一遍，而是**照 a2e 的图元与示例镜头抄**。

## 一、图元：直接用 a2e `template/src/ui.tsx` 这一套

| a2e 图元 | 签名要点 | 竖版怎么用 |
|---|---|---|
| `Svg` | 全幅 SVG 容器，`position:absolute; left:0; top:0; overflow:visible` | 竖版容器 1080×1920；**要压在卡片上的图形，`Svg` 必须排在卡片之后**（lessons：否则被卡片底整块盖掉） |
| `LineArrow` | `x0,y0 → x1,y1`，`p` 生长进度；**杆先长、三角头骑在当前尖端**；`headL/headW/rodW/dashed` | 所有直线箭头一律用它。禁止 `div + rotate` 拼箭头 |
| `ArrowH` | `scaleX(p)` 自根部长出的横向箭头（div 版） | 只在「纯水平、不需要斜」的短箭头用 |
| `Check` / `Cross` | `polyline` + `strokeDasharray/offset` 做 draw-on；`p=0` 返回 null（否则 linecap 留一个圆点） | 网格里打勾/打叉 |
| `Box` / `Pill` / `DocIcon` / `DBIcon` / `ChunkCard` | 线框卡、胶囊、文档、库、文本块 | 结构件主体；`DocIcon` 至少 96×120，别当 64px 小图标用 |
| `CText` / `MonoText` / `Counter` | 按中心点定位的大字 / 等宽 / 计数 | 柱顶数值、年份、倍数 |

**竖版取值**（纸色编辑排版，不搬黑底紫光）：`fill = #FAFAF8 / #F5F5F5`、`stroke = #2D3142`、强调 `#BF4520`、辅助线 `#D9D7D1`、`Svg` 不加 bloom（`bloom=false`）。字阶与坐标仍用 `vbase/tokens` 的 T/S/PAD。

## 二、示例镜头里已经写好的四类画法（照抄，别重新发明）

1. **批量长柱**（`examples/rag/shots_src/G1/SC05.tsx` 成本柱）：`BASE_Y` 一条基线；每根柱 `div` 宽 46–170、`border: 1px`、`height = h × (1 - powOutRemain(n, 16, 2.5))`；数值用 `CText` 挂在柱顶上方固定偏移；多根之间**2 帧错峰**。→ 用于 SC04 / SC05 / SC09 的柱图。
2. **流程 / 汇流**（同目录 `G3/SC12.tsx` 四文件 → 箭头 → 解析器 → 文档卡）：来源图标排一列、`LineArrow` 逐个 draw-on 到中继，再一条主线到接收方；接收方是**一张 ≥440×300 的卡**，卡内有标题与 2–3 行内容，不是一个 64px 图标。→ 用于 SC02。
3. **分支汇合**（`G3/SC22.tsx`）：三条分支各一个 `LineArrow`，末端汇到同一节点；分支卡 2 帧错峰。→ 用于 SC08 左右对开（品牌 → 创作者）。
4. **对比/高亮**（`G1/SC05` 的灰→紫切换 + `G4` 的 `Check/Cross`）：一条「当前项」用强调色，其余灰；交叉点用一个 `Marker`（10px 实心方块）标在被反超条的右端。→ 用于 SC07。

## 三、竖版三段带（1080×1920，PAD 96）

| 带 | y | 放什么 |
|---|---|---|
| 页眉 | 116–166 | `Head` |
| 标题 | 210–540 | `Kick` + `Huge`（≤2 行，96–150px） |
| 结构 | 580–1250 | 图表 / 卡片 / 清单；主体 ≥440×300 或 ≥170px 高 |
| 判词 | 1300–1580 | `Rule` + 34–38px 两行；底边 ≤1614 |
| 页脚 | 1698–1746 | `Foot`（无页码） |

**先定带，再落坐标。** 第一轮就是先画柱再摆字，柱子顶进标题带了。

## 四、图表的四条硬约束

- 柱图：基线固定 `y=1240`，满高 ≤640（柱顶 ≥600）；数值挂柱顶 45px，年份挂基线下方 22px。
- 横条：`y=960`，高 180–220，内部两行（口径 + 一句解释，行距 ≥44）。
- 箭头：一律 `LineArrow`，`p` 用 16–28 帧走完；箭头对面是「接收方实体」，不是空白。
- 不用天平：竖版里梁/盘/支点互相压；「价格 ≠ 效果」用**两条不等长横条 + 一条虚线等高参考**表达。

## 五、禁区（都踩过）

- `div + transform: rotate(±24deg)` 拼箭头 —— 线一斜头就飞（EP03 第一轮的 SC02、SC14）。
- `Glyph kind="coin"` 当图表主体 —— 64px 小图标，撑不起主区，还像碎屑。
- 柱高 `top = 基线 - 高` 与大数字同区间 —— 必压字（SC04、SC05、SC09）。
- 判词结束在 1300 就不往下排 —— 页面 1300–1698 会空 400px（EP03 第一轮 13 镜都有）。
- 用 `div` 手算旋转去对 SVG 箭头 —— 让 `LineArrow` 自己算。
