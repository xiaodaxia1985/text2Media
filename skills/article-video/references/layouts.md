# 十二套版面（A~L）

`compose_layouts.py` 里的每一套，换的都不是「文字放哪」，而是**页与字的图文关系**。看一支片是不是"做出来像一个模板",就数它用了几套这个表里的手法。

## 画布与常量

```
W H        = 1920 1080   （横页原生画幅；竖版改 1080×1920，常量在文件头）
PAD        = 84
PAGE_W     = 1184        （页面缩放后高度上限 960，宽度按比例算）
PAGE_H     = 960
BIG        = 46          横排大字号
COL_W      = 440         右栏宽度
FONT       = ARTICLE_VIDEO_FONT / FIGKIT_FONTS / 本机默认，找汇文明朝体 .otf
NO_HEAD    = False       无字模式开关，命令行 --no-head 打开
SCR        = round(H * 0.15)   无字时底部留给字幕带的高度
```

页面缩放**全片必须同一个系数**（`PAGE_H / 最高的那页`），否则每镜字大小在跳，观众会以为换了片子。

## primitives

| 函数 | 干什么 |
|---|---|
| `page_at(im, k, anchor)` | 按系数 k 缩放页面；`anchor` = `(x, y)` 定点、`(x, None)` 垂直居中、`(x, 52)` 显式 y；`'left'/'right'/'center'` 取横向 |
| `htext(d, text, x, font, w, mask=False, align, y_top)` | 横排大字，自动折行；`mask=True` 先铺纸色底衬 |
| `vtext(d, text, x, font, cols, gap)` | 竖排，自动分列，列距 `gap` |
| `idx(d, i, n, x, y, f, align)` | `04 / 10` 编号 |
| `rule(d, (x0,y0), (x1,y1))` | 1px 细线 |

## 逐套

### A · 页左·右栏横排
页 `k=1` 贴左，字在右栏 46px 起排。最稳的一档，用来"让人先把页面读一遍"。

### B · 页右·左栏横排
页贴右（保留 `PAD` 边距），字在左侧 49px。适合"结论先出口，再用页面兑现"。

### C · 页左·竖排单列
页贴左，竖排在页面右缘外 40px，34px 起。像在页边写批注。**只给短句**（≤18 字），长句会顶出画面底部。

### D · 页右·竖排单列
和 C 镜像。作用是**换气**：上一镜横排、这一镜竖排，画面立刻换调。

### E · 页左·竖排双列
40px、两列、列距 54。给 19~26 字的长句：竖着压成两条，比横排折三行好看。

### F · 批注式
页 `k=1` 铺满整幅，页面右缘外 26px 画一条竖线，再往外 96px 竖排小字。页自己就是主角，字只做旁注。

### G · 字块切页
页 `k=1` 铺满，字块从 `PAD + PAGE_W - 58` 起排，带纸色底衬。
**底衬只许压页面右侧白边那 58px**：压多了会盖掉正文（第一版就这么干过,把 waterfall 的第五根柱吃掉了）。

### H · 开窗放大
页 `k=0.66` 在左上，右下 `1060,430` 开 760 宽的窗口，裁页面**右下 52%×48%** 放大，窗口上方标「局部放大」。
裁太大（比如 76%×68%）会变成"整页缩小再放一遍"，读者第一反应是复制粘贴。

### I · 字出血
页 `k=0.66` 在左上；92px 大字右对齐贴右边缘，压在下半幅。一句就是全片结论时用。
页必须**移上去**，否则大字压到页脚注释（这一条第一版也踩过）。

### J · 竖线分栏
页 `k=0.74` 贴右，竖线在 `x=516` 从 90 到 H-90，字在竖线左侧竖排两列。给转折：一条线把两件事切开。

### K · 巨号编号垫底
190px 的 `01…10` 画在左上（`#e0dedb`），页 `k=0.8` 从 `x=520` 起，字在页面下方。
只调节奏，不承担信息。**长片里连用两次会显眼，一言最多两次**。

### L · 出血压边
页 `k=0.9` 贴右，右侧**出画 62px**；左侧竖排两列。收束用，"翻过去一页"的手感。
出血量超过 70px 就会裁到正文（上一版 150px 把第三列卡片切了）。

## 编排器

```
PREFER = {
  short: C, K, F, A, B, L      # ≤12 字
  mid:   A, B, D, E, J, H      # 13~18 字
  long:  G, E, I, A, H         # >18 字
}
choose(text, used) 按 band 取第一个不在最近两镜的
```

`shot_plan.py` 生成的 `layout` 会覆盖这里的自动挑选（显式优先）。`--only A,B` 可只渲指定几套做样张。

## 三处踩过的坑（复述一遍，避免重犯）

1. **纸色遮罩盖正文**：G 的底衬只能压右侧 58px 留白。
2. **"开窗"变"复制两遍"**：H 必须裁一小块局部，不能裁大半页。
3. **出血裁到正文**：L 的出血量 ≤ 62px，靠页面自身的左右留白吃饭。

## 一页两拍：推近帧怎么裁（第四坑）

`frames: 2` 的镜会多出一张 `<页名>b.png`：同一构图的推近，音频仍是同一段、时长对半分。第一版按**画面重心**裁，结果 G 的右栏大字被裁成半句「信托一次办三件…」——**推近把字幕切了**。

规则改成按**字在哪一侧**裁：

| 版式 | 保留哪侧 | 效果 |
|---|---|---|
| A B C D E F G H J | 右侧 | 字在右，推的是页面左半 |
| I L | 左侧 | 字在左竖排 |
| K | 下沿 | 字在页面之下 |

裁掉 1/1.26 再放大回 1920×1080：字一个不丢，页被推近。

## K 的编号换角

巨号编号原本钉死在左上。长片里 K 会用两次，同一个角连着出现两次就露馅。现在按**镜次奇偶**换角：偶数镜左上，奇数镜右下（压到画面下沿，编号从页边"漏"出来）。只支持这两个角。

## 无字模式（`--no-head`）：S1~S12 各怎么让位

关掉屏幕大字之后，十二套要换的就不是「字怎么排」，而是「图放哪、装饰线挂哪」。统一三条：

1. 图底边贴字幕带上沿（`head_y()`），不是画布垂直居中——居中会让图飘在半空、图与字幕之间空出 200px。
2. 镜号与装饰线一律挂**图上方**；图下方是字幕带，压进去就会被字幕盖住。
3. `strip_fit` 的 `max_bleed` 从 1.04 收到 0.96：视频页的图形区几乎贴边，1.04 加上运镜推 1.025 会切字（实测 01-event 的「1993」「辞去…全部职务」两处被裁）；0.96 × 1.025 ≈ 0.984，仍在画布内。

| 版式 | 无字时图高 | 图怎么落 | 装饰 / 镜号 |
|---|---|---|---|
| S1 上图下文 | 要 0.64H，受限宽仍是 0.536H | 底贴 | 通栏细线在图上方 34px，镜号再上一格 |
| S2 上文下图 | 0.56H | 底贴、居中 | 细线跟图宽（y−34），镜号挂线右端 |
| S3 题签左 | 0.54H | 底贴 | 90 号编号压线左上，细线从 `PAD+130` 起，橙短线接在线下 22px |
| S4 题签右 | 0.54H | 底贴 | 橙短线右对齐 420 宽，74 号镜号退到线外右上 |
| S5 出血压顶 | 0.60H | 底贴 | 左侧 420 宽橙短线在图上方，镜号右上 |
| S6 缩图巨字 | 0.34H | 底贴 | 细线跟图宽（y−30），镜号 y−58；整片最「远」的一刀，给一句总结让位 |
| S7 双块并置 | 0.54H，gap 60 | 两块并置、底贴 | 竖线只向上出头 44px（向下出头会落进字幕带），镜号 y−70；双块是这套的全部意义，块不动 |
| S8 顶出血压线 | 0.58H | 顶边轻压 22px，保留「这页没摆正」的语义 | 左侧 420 橙线在图上方 |
| S9 斜置 | 0.50H | 居中底贴 | **不倾斜**：宽条素材一转角，四角露纸色白边；时间轴那类图，水平线本身就是读向基准，斜 2.2° 会把「哪边是起点」搞乱。身份靠通栏细线 + 镜号压线右端补 |
| S10 开窗 | 0.60H（窄页仍按 0.72 宽靠左） | 底贴；窄页 y=120 | 窗保留、位置不动；镜号挂图上方 50px |
| S11 刻度线 | 0.44H | 底贴 | 八齿刻度线紧贴图上方 88px，镜号挂刻度右端外侧 |
| S12 巨号垫底 | 0.48H | 底贴 | 150 号编号退成 `#e2e0dd` 底纹仍在左上，图上方 260 宽短细线收住 |

**没改的**：`A`~`L` 十二套整页版式仍是带字版。`--no-head` 下若 shot plan 显式给了 A~L，那一镜照样出大字，混排就是一屏有字、一屏没有。
