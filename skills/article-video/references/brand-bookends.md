## 一、片头 · 片尾

### 1.1 只用自有标记

- 标记几何与 `brand/logo/mark.svg` 同源：**三级台阶 + 右上一个点**，外套一道细圆环（r 46，细线）。
- 浅底一律纯黑 `#0C0C0C`（《LOGO 使用规范》：白底/浅底用纯黑，柠檬绿只给深底）。
- **不放人物照片**（包括文章作者本人）。旧横版片头里的柠檬绿 logo、Dan Koe 头像均已作废。
- 不描边、不加阴影、不加渐变、不改台阶数量。

### 1.2 片头动画顺序（卡框先立住，再让标记一级一级长出来）

1. 页眉导轨 + 引子 + 主句两行先出；
2. 卡框（888×600，与正片同款 Panel）与圆环先立住——**整页骨架 1 秒内到位**，不许"空场等字"；
3. 三级台阶从同一基线**一级一级升起**（每级 ~0.47s），点最后落下；
4. 字标出现在转角之后，13 格刻度点亮第 1 格收尾。

### 1.3 文案（用户定稿，一字不许改）

- 片头：「一页识君，天下谁人不识君。大家好，我是个人商业创造者。」
- 片尾：「关注、点赞、收藏，下期见。」
- 片头卡内可放：字标「个人商业创造者」、`INDEPENDENT BUSINESS BUILDER`、品牌释义「把能力，一层层搭成系统」。**不许把「一级一级往上搭」这类临时标语放进片头**。

### 1.4 片尾结构

- 三格行动清单（关注 / 点赞 / 收藏）：编号 + 左色条 + 右线框图标 + `STEP 0x`；
- 下压「下期见」判词 → 自有圆环标记 + 字标 → 13 格轨道全部点亮；
- 四段配音逐词对位：关注 0.00s / 点赞 0.64s / 收藏 1.68s / 下期见 2.48s。

## 三、垫乐

**定版：极简钢琴铺底，-13 dB，不做旋律主导的曲子。**（2026-11-19 用户三次试听后拍定）

| 项 | 定值 |
|---|---|
| 风格 | 极简钢琴，68 BPM，无鼓、无人声、**无旋律句**；和弦 Am7 → Fmaj7 → Cmaj7 → G6，8s 一小节，每小节一记软和弦 + 偶尔单音 |
| 时长 | 与成片等长（88s 级），段尾淡出 |
| 电平 | **-13 dB** 混入；混完整片 LUFS 与无乐版一致（实测 -16.7 LUFS） |
| 淡入淡出 | 淡入 2.0s、淡出 3.4s（淡出起点 = 总长 − 3.4s） |
| 源 | `engine/scripts/make_bed.py` → `engine/public/assets/brand/bed.wav`（可复现，可改和弦/BPM） |
| 工具 | `tools/t2m-video/mix_bgm.ps1 -Video <mp4> -Bgm <wav> -Out <mp4> [-Db -13]`，视频流直接 copy |

判据：**有乐版与无乐版的 `ebur128` 积分响度必须相同**，一旦抬高就说明音乐压过了旁白。

### 3.1 试过并否掉的（别再折腾第二次）

| 做法 | 结果 | 用户判词 |
|---|---|---|
| 生成式真旋律钢琴（88s 新古典、右手连续旋律句），底 -25 LUFS | 否 | 「音乐抢了，还要再低再轻点」 |
| 同上降到 -34 LUFS + 侧链 4:1 | 否 | 「再降，都还有点强」 |
| 同上降到 -40 LUFS | 否 | 「问题不在音量，在旋律辨识度太高」——有声小也会被留意 |
| 纯氛围铺底（长音和弦 + 空气底噪，无旋律），-33 LUFS | 否 | 仍回到极简钢琴 -13 dB |
| 把音乐抬到能"听见旋律"的电平 | 否 | 口播片里音乐只是氛围，不能当主角 |

结论一句话：**口播片垫乐不靠音量取胜，靠"听不出旋律、只留一点质感和呼吸"**。旋律越清楚，越容易抢戏；把旋律拿掉、音量压到 -13 dB，反而最稳。

## 四、三段合成

```
ffmpeg -f concat -safe 0 -i concat-<EP>.txt -c copy <EP>_FULL.mp4
```

`concat-<EP>.txt` 三行：`file 'HEAD.mp4'` / `file 'EP01.mp4'` / `file 'TAIL.mp4'`。三段参数必须完全一致（1080×1920 / 30fps / h264 / aac 48k 2ch），否则 -c copy 会失败。
