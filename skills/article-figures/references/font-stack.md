# 字体：按字号分工，不是全局替换

这一页的字体不是「挑几支好看的」，是**每个字号段各管一件事**。整页只有一个印刷腔，靠的是分工，不是数量。

## 分工表

| 位置 | 字体 | 字号 / 字重 | 为什么是它 |
|---|---|---|---|
| h1 标题 | 汇文明朝体 | 62px / 400 | 旧字形、横细竖粗对比强，不是"现代编辑体"的中性脸 |
| dek 导语 | 霞鹜文楷 | 18.5px / 400 / lh 1.92 | 楷体带来书卷气，且不抢标题的骨 |
| 大数字（h1、导语里） | EB Garamond | 400 + `lnum` | 老式数字默认下沉（3/4/5/7/9），必须开 lining figures |
| 金句 / callout | 汇文明朝体 | 26px / 400 / lh 1.68 | 和标题同一支字体，整页钉成一个腔 |
| 标签 / 轴 / 图例 / 节点名 | 思源黑 | 400 / 600 | 这些是"系统语言"，不该有笔锋 |
| SVG 内小数值（柱顶 14px 等） | 思源黑 | 600 | 见下面那个坑 |

## 三条从失败里换来的规矩

**1. 不要在小编号上换衬线体。**
最初把 Garamond 套到 SVG 里 14px 的柱顶数值，结果浏览器给**合成假粗**：Garamond 只有 400，页面请求 600，浏览器就伪造一版，笔画糊成一团；同时叠上 Garamond 默认的老式数字，3/4/5/7/9 全部下沉，和柱底对不齐。
→ 结论：**大字换 Garamond，小数值维持思源黑。** 换字体不是全局 CSS 替换。

**2. 只有 400 的字不能承担字重层级。**
汇文明朝体只有 400，所以金句从"宋 420 伪半粗"改成"汇文 400 / 26px"——靠**字号**立起来，不靠加粗。同理文楷不能做标题：60px 上发飘，气质从印刷品滑向手写感。

**3. 别用这三种"AI 味"标识。**
全大写 tracked eyebrow、`A · B · C` 中点串、小数据用等宽体——这三样在生成式页面上出现频率高到成了指纹。中文页面还有个更明显的：给正文加**合成假斜体**（浏览器倾斜，字形是假的）。要强调就换字号或换留白。

## 旧字形：先看授权，再看好看

| 字体 | 包里元数据 | 观感 | 能否内嵌发布 |
|---|---|---|---|
| 思源宋（Noto Serif SC） | SIL OFL | 现代编辑体，四平八稳 | 可以 |
| **汇文明朝体** | `Copyright Public Domain` | 字面更大、撇捺有书写感、标点旧式位置 | **可以**（本 skill 用它做标题与金句） |
| 京華老宋体 | `Copyright TerryWang. All rights reserved` | 与思源宋差别有限，远看像同一支 | **不可以**——正文都说"免费商用"，但元数据保留所有权利；把字体裁片 base64 内嵌进网页是**分发**行为 |

教训：判断授权读 **字体文件里的 copyright 字段**，不要读文章标题。中文社区很多"免费商用"字体，元数据写的却是保留所有权利。

## 内联是怎么做的（`scripts/fontkit.py`）

1. Noto 系、文楷、Garamond 都是按 `unicode-range` 切好的 ~100 个 woff2 分片；汇文、京華是单文件。
2. 分片字体：只看这页字符落在哪几个分片；单文件字体：整页字符集丢给 subset。
3. 每个命中的分片用 `fontTools.subset` 裁到页内字形，**可变轴保留**（`fvar` / `gvar` 都在）。
4. base64 内联成 `@font-face`；分片才带 `unicode-range`，单文件不带。

实测：单页 **2.5MB → 220–300KB**；一个 105KB 分片裁到 2 个字形剩 1.6KB。

## 依赖坑

- 汇文明朝体是 OTF + SVG 表字体，`fontTools` 裁它必须装 **lxml**，否则报 `No module named 'lxml'`。
- `pip` 走默认源/清华源都可能失败；用阿里云镜像（见 SKILL.md）。
- 字体包走 npmmirror 的 `npm pack`；`@fontpkg/*` 系列包就在上面，不用去 GitHub Release。
